## 1. 项目简介

### 1.1 什么是 poi-excel

poi-excel 是一个基于 Apache POI 的 Java Excel 操作工具库，旨在简化 Excel 的导入导出操作。它采用链式调用的方式，让开发者能够以最少的代码完成复杂的 Excel 处理任务。

### 1.2 主要特性

- **纯编码实现**：无需注解，无侵入代码，提供更好的复用性
- **链式调用**：流畅的 API 设计，代码简洁易读
- **强大的导入功能**：支持单元格级别校验、错误输出、大数据批处理、数据转换、图片导入等
- **全面的导出功能**：支持简单/复杂表头、自定义样式、公式、合计行、序号、图片、单元格合并等
- **模板替换**：支持读取 Excel 模板并替换变量（文本和图片）
- **多格式支持**：支持 xls（Excel 2003）和 xlsx（Excel 2007+）格式

### 1.3 环境要求

- Java 8+
- Apache POI 5.2.3+

### 1.4 xls vs xlsx 选择建议

| 格式 | 速度 | 单Sheet最大行数 | 文件体积 | 适用场景 |
|------|------|-----------------|----------|----------|
| xls  | 较快 | 65,535 行       | 较大     | 小数据量、兼容旧版Excel |
| xlsx | 较慢 | 1,048,576 行    | 较小     | 大数据量、现代Excel |

## 2. 快速开始

### 2.1 Maven 依赖

```xml
<dependency>
    <groupId>com.github.stupdit1t</groupId>
    <artifactId>poi-excel</artifactId>
    <version>3.3.1</version>
</dependency>
```

### 2.2 核心入口类

所有操作都通过 `ExcelHelper` 类进行：

```java
import com.github.stupdit1t.excel.core.ExcelHelper;

// 导出操作
ExcelHelper.opsExport(PoiWorkbookType.XLSX)

// 导入操作
ExcelHelper.opsParse(YourClass.class)

// 模板替换操作
ExcelHelper.opsReplace()
```

### 2.3 第一个导出示例

```java
// 准备数据
List<User> users = getUserList();

// 执行导出
ExcelHelper.opsExport(PoiWorkbookType.XLSX)
    .opsSheet(users)
    .opsHeader().simple()
        .texts("姓名", "年龄", "邮箱")
        .done()
    .opsColumn()
        .fields("name", "age", "email")
        .done()
    .export("users.xlsx");
```

### 2.4 第一个导入示例

```java
// 执行导入
PoiResult<User> result = ExcelHelper.opsParse(User.class)
    .from("users.xlsx")
    .opsSheet(0, 1, 0)  // sheet下标, 表头行数, 尾部行数
    .opsColumn(true)    // 自动映射列
    .done()
    .parse();

// 检查错误
if (result.hasError()) {
    System.out.println(result.getErrorInfoString());
}

// 获取数据
List<User> users = result.getData();
```

## 3. 核心概念

### 3.1 工作簿类型 (PoiWorkbookType)

```java
public enum PoiWorkbookType {
    XLS,      // Excel 2003 格式 (.xls)
    XLSX,     // Excel 2007+ 格式 (.xlsx)
    BIG_XLSX  // 大数据导出格式，防止OOM
}
```

**BIG_XLSX 配置选项：**

```java
PoiWorkbookType.BIG_XLSX
    .rowAccessWindowSize(200)      // 内存中保留的行数，默认200
    .compressTmpFiles(true)        // 是否压缩临时文件
    .useSharedStringsTable(true);  // 是否使用共享字符串表
```

### 3.2 单元格位置 (CellPosition)

```java
public enum CellPosition {
    TITLE,   // 大标题
    HEADER,  // 表头
    CELL,    // 数据单元格
    FOOTER   // 尾部
}
```

### 3.3 列索引 (Col)

提供 A-ZZ 的列索引枚举，用于导入时指定列：

```java
Col.A, Col.B, Col.C, ... Col.Z,
Col.AA, Col.AB, ... Col.ZZ
```

### 3.4 解析结果 (PoiResult)

```java
PoiResult<T> result = ...;

// 判断是否有错误
result.hasError();

// 判断是否有数据
result.hasData();

// 获取数据列表
List<T> data = result.getData();

// 获取错误信息
List<ErrorMessage> errors = result.getError();

// 获取格式化的错误信息字符串
String errorStr = result.getErrorInfoString();

// 获取行级别的错误信息
String lineError = result.getErrorInfoLineString();
```

## 4. 导出功能详解

### 4.1 简单导出

最基础的导出方式，适用于简单表格：

```java

    .opsSheet(dataList)
    .opsHeader().simple()
        .texts("项目名称", "所属区域", "省份", "市", "负责人", "创建时间")
        .done()
    .opsColumn()
        .fields("projectName", "areaName", "province", "city", "leader", "createTime")
        .done()
    .export("simple.xlsx");
```

    .opsSheet(dataList)

        .texts("项目名称", "所属区域", "省份")

### 4.3 复杂表头导出

支持多行合并的复杂表头，提供三种坐标定位方式：

```java
ExcelHelper.opsExport(PoiWorkbookType.XLSX)
    .opsSheet(dataList)
    .opsHeader()
        .complex()
            // Excel坐标方式: "A1:K1"
            .text("项目资源统计", "A1:K1")
            // 字母坐标方式: "起始行,结束行,起始列,结束列"
            .text("序号", "2,3,A,A")
            // 数字坐标方式: 起始行, 结束行, 起始列, 结束列 (从0开始)
            .text("基本信息", 1, 1, 1, 4)
            .text("项目名称", "3,3,B,B")
            .text("所属区域", "3,3,C,C")
            .text("省份", "3,3,D,D")
            .text("市", "3,3,E,E")
            .done()
    .opsColumn()
        .fields("projectName", "areaName", "province", "city")
        .done()
    .export("complex_header.xlsx");
```

### 4.4 列属性详细配置

```java
ExcelHelper.opsExport(PoiWorkbookType.XLSX)
    .opsSheet(dataList)
    .opsHeader().simple()
        .texts("城市", "创建时间", "得分", "平均分")
        .done()
    .opsColumn()
        .field("city")
            .width(6000)                              // 列宽
            .height(500)                              // 行高
            .wrapText()                               // 自动换行
            .dropdown("北京", "上海", "广州", "深圳")   // 下拉框
            .comment("请选择城市")                     // 批注
            .mergerRepeat()                           // 相同值合并
            .align(HorizontalAlignment.CENTER)        // 水平居中
            .valign(VerticalAlignment.CENTER)         // 垂直居中
            .color(IndexedColors.RED)                 // 字体颜色
            .backColor(IndexedColors.YELLOW)          // 背景色
        .field("createTime")
            .pattern("yyyy-MM-dd HH:mm:ss")           // 日期格式化
            .mergerRepeat("areaName")                 // 按指定字段合并
        .field("score")
            .pattern("0.00")                          // 数字格式化
        .field("avg")
            .pattern("0.00%")                         // 百分比格式化
        .done()
    .export("column_config.xlsx");
```

### 4.5 数据回调处理

在导出时对数据进行动态处理：

```java
ExcelHelper.opsExport(PoiWorkbookType.XLSX)
    .opsSheet(dataList)
    .opsHeader().simple().texts("城市", "状态").done()
    .opsColumn()
        .field("city")
            .map((value, row, style, rowIndex) -> {
                // value: 当前单元格值
                // row: 当前行数据对象
                // style: 可修改的样式对象
                // rowIndex: 数据行索引
                
                if ("北京".equals(value)) {
                    style.setBackColor(IndexedColors.YELLOW);
                    style.setComment("首都");
                }
                return value;  // 返回最终显示的值
            })
        .field("status")
            .map((value, row, style, rowIndex) -> {
                // 返回公式
                return "=IF(A" + (rowIndex + 2) + "=\"北京\",\"重点\",\"普通\")";
            })
        .done()
    .export("callback.xlsx");
```

### 4.6 尾部行设计

```java
ExcelHelper.opsExport(PoiWorkbookType.XLSX)

```

### 4.10 数据校验

导出模板时添加数据校验规则：

```java
ExcelHelper.opsExport(PoiWorkbookType.XLSX)
    .opsSheet(Collections.emptyList())
    .opsHeader().simple()
        .texts("姓名", "手机号", "生日", "月龄", "性别", "来源")
        .done()
    .opsColumn()
        .field("姓名")
        .field("手机号")
            .verifyText("11~11", "请输入11位手机号！")      // 文本长度校验
        .field("生日")
            .pattern("yyyy-MM-dd")
            .verifyDate("2000-01-01~2030-12-31")           // 日期范围校验
        .field("月龄")
            .verifyIntNum("1~120", "请输入1-120的整数")     // 整数范围校验
        .field("性别")
            .dropdown("男", "女")                          // 下拉框
        .field("来源")
            .dropdown(sourceList)                          // 动态下拉框
        .done()
    .export("template.xlsx");
```

**校验类型说明：**

| 方法 | 说明 | 示例 |
|------|------|------|
| `verifyText(range, msg)` | 文本长度校验 | `"1~20"` 表示1-20个字符 |
| `verifyIntNum(range, msg)` | 整数范围校验 | `"1~100"` 表示1-100 |
| `verifyFloatNum(range, msg)` | 浮点数范围校验 | `"0.0~100.0"` |
| `verifyDate(range, msg)` | 日期范围校验 | `"2020-01-01~2030-12-31"` |
| `verifyCustom(formula, msg)` | 自定义公式校验 | `"VALUE(A1:A100)"` |
| `dropdown(items)` | 下拉框 | 字符串数组或集合 |

## 5. 导入功能详解

### 5.1 导入到 JavaBean

#### 5.1.1 自动映射列

按照 JavaBean 字段顺序自动映射 Excel 列：

```java
PoiResult<ProjectEvaluate> result = ExcelHelper.opsParse(ProjectEvaluate.class)
    .from("data.xlsx")
    .opsSheet(0, 1, 0)  // sheet下标, 表头行数, 尾部行数
    .opsColumn(true)    // true 表示自动映射
    .done()
    .parse();

if (result.hasError()) {
    System.out.println(result.getErrorInfoString());
}
List<ProjectEvaluate> data = result.getData();
```

#### 5.1.2 自动映射 + 指定列覆盖

```java
PoiResult<ProjectEvaluate> result = ExcelHelper.opsParse(ProjectEvaluate.class)
    .from("data.xlsx")
    .opsSheet(0, 1, 0)
    .opsColumn(true)
        // 覆盖特定列的处理规则
        .field(Col.H, ProjectEvaluate::getScore)
            .type(double.class)
            .scale(2)  // 保留2位小数
    .done()
    .parse();
```

#### 5.1.3 手动指定列映射

```java
PoiResult<ProjectEvaluate> result = ExcelHelper.opsParse(ProjectEvaluate.class)
    .from("data.xlsx")
    .opsSheet(0, 1, 0)
    .opsColumn()  // 不自动映射
        .field(Col.A, "projectName")
        .field(Col.B, "areaName")
        .field(Col.C, ProjectEvaluate::getProvince)  // 方法引用
        .field(Col.H, "score")
    .done()
    .parse();
```

#### 5.1.4 完整校验示例

```java
Map<String, Integer> cityMapping = new HashMap<>();
cityMapping.put("北京", 1);
cityMapping.put("上海", 2);
cityMapping.put("广州", 3);

PoiResult<ProjectEvaluate> result = ExcelHelper.opsParse(ProjectEvaluate.class)
    .from("data.xlsx")
    .opsSheet(0, 1, 1)
    .opsColumn()
        .field(Col.A, "projectName")
            .trim()                          // 去除空格
            .notNull()                       // 不能为空
            .defaultValue("默认项目")         // 默认值
            .regex("中青旅\\d{2}")            // 正则校验
        .field(Col.D, "province")
        .field(Col.E, "cityKey")
            .notNull()
            .map(cityMapping::get)           // 值映射转换
        .field(Col.H, "score")
            .scale(2)                        // 保留2位小数
        .field(Col.J, "createTime")
            .format("yyyy-MM-dd")            // 日期格式
    .done()
    .parse();
```

### 5.3 列校验规则详解

| 方法 | 说明 | 示例 |
|------|------|------|
| `notNull()` | 不能为空 | `.notNull()` |
| `trim()` | 去除首尾空格 | `.trim()` |
| `defaultValue(val)` | 设置默认值 | `.defaultValue("默认")` |
| `regex(pattern)` | 正则校验 | `.regex("\\d+")` |
| `format(pattern)` | 日期格式化 | `.format("yyyy-MM-dd")` |
| `scale(n)` | 数字精度 | `.scale(2)` |
| `type(cls)` | 强制类型转换 | `.type(Double.class)` |
| `map(func)` | 值转换/映射 | `.map(v -> v.toString())` |

### 5.5 大数据分批导入

避免一次性加载大量数据到内存：

```java
ExcelHelper.opsParse(ProjectEvaluate.class)
    .from("big_data.xlsx")
    .opsSheet(0, 1, 0)
    .opsColumn(true).done()
    .parsePart(1000, result -> {  // 每1000条处理一次
        if (result.hasError()) {
            System.out.println(result.getErrorInfoString());
        }

        saveToDB(batch);
    });
```

### 7.1 全局样式覆盖

通过实现 `ICellStyle` 接口自定义样式：

```java
ICellStyle titleStyle = new ICellStyle() {
    @Override
    public CellPosition getPosition() {
        return CellPosition.TITLE;  // 指定样式位置
    }
    
    @Override
    public short getHeight() {
        return 600;  // 行高，-1表示不设置
    }
    
    @Override
    public void handleStyle(Font font, CellStyle cellStyle) {
        // 字体设置
        font.setFontHeightInPoints((short) 20);
        font.setBold(true);
        font.setColor(IndexedColors.RED.index);
        
        // 单元格样式
        cellStyle.setAlignment(HorizontalAlignment.CENTER);
        cellStyle.setVerticalAlignment(VerticalAlignment.CENTER);
        cellStyle.setFillForegroundColor(IndexedColors.YELLOW.index);
        cellStyle.setFillPattern(FillPatternType.SOLID_FOREGROUND);
    }
};

ExcelHelper.opsExport(PoiWorkbookType.XLSX)
    .style(titleStyle)  // 应用自定义样式
    .opsSheet(dataList)
    // ...
```

## 9. 常见问题

### 9.1 导出时出现 OOM

**问题**：导出大量数据时内存溢出

**解决方案**：使用 `BIG_XLSX` 类型

```java
ExcelHelper.opsExport(PoiWorkbookType.BIG_XLSX)
    // ...
```

### 9.2 导入时日期格式不正确

**问题**：日期字段解析失败

**解决方案**：指定日期格式

```java
.field(Col.A, "createTime")
    .format("yyyy-MM-dd HH:mm:ss")
```

### 9.3 数字精度丢失

**问题**：浮点数精度问题

**解决方案**：使用 `scale()` 指定精度或使用 `BigDecimal` 类型

```java
.field(Col.A, "amount")
    .type(BigDecimal.class)
    .scale(2)
```

### 9.4 中文乱码

**问题**：导出的文件名或内容中文乱码

**解决方案**：确保项目编码为 UTF-8，Web 导出时正确设置响应头

```java
response.setContentType("application/vnd.openxmlformats-officedocument.spreadsheetml.sheet");
response.setCharacterEncoding("UTF-8");
String fileName = URLEncoder.encode("中文文件名.xlsx", "UTF-8");
response.setHeader("Content-Disposition", "attachment;filename=" + fileName);
```

### 9.5 下拉框数据过多

**问题**：xls 格式下拉框数据量有限制

**解决方案**：使用 xlsx 格式，或减少下拉选项数量

### 9.6 图片不显示

**问题**：导出的图片不显示

**解决方案**：确保图片字段为 `byte[]` 类型，且数据不为空

```java
public class Entity {
    private byte[] img;  // 必须是 byte[] 类型
}
```

### 9.7 公式不计算

**问题**：导出的公式显示为文本

**解决方案**：公式必须以 `=` 开头

```java
.map((val, row, style, idx) -> "=SUM(A1:A10)")
```

### Spring Boot Web 导出示例

```java
@RestController
@RequestMapping("/excel")
public class ExcelController {

    @GetMapping("/export")
    public void export(HttpServletResponse response) {
        List<User> users = userService.findAll();
        
        ExcelHelper.opsExport(PoiWorkbookType.XLSX)
            .opsSheet(users)
            .opsHeader().simple()
                .title("用户列表")
                .texts("ID", "姓名", "邮箱", "创建时间")
                .done()
            .opsColumn()
                .fields("id", "name", "email")
                .field("createTime").pattern("yyyy-MM-dd HH:mm:ss")
                .done()
            .export(response, "用户列表.xlsx");
    }
    
    @PostMapping("/import")
    public Result importUsers(@RequestParam("file") MultipartFile file) {
        PoiResult<User> result = ExcelHelper.opsParse(User.class)
            .from(file.getInputStream())
            .opsSheet(0, 1, 0)
            .opsColumn()
                .field(Col.A, "name").notNull().trim()
                .field(Col.B, "email").notNull().regex("^[\\w-]+@[\\w-]+\\.[a-z]+$")
                .field(Col.C, "age").type(Integer.class)
                .done()
            .parse();
            
        if (result.hasError()) {
            return Result.fail(result.getErrorInfoLineString());
        }
        
        userService.batchSave(result.getData());
        return Result.success("导入成功：" + result.getData().size() + " 条");
    }
}
```
